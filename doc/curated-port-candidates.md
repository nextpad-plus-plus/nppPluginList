## Port progress (→ macOS)

**Pipeline (validated on the pilot):** each plugin → `nppPluginsMacOS/<folder>.macos/` (new folder, existing ones untouched) → copy LICENSE/README/icons → convert `.ico`/`.bmp` toolbar icons to transparent PNG (`sips`) → faithful `.mm` port (logic verbatim; Win32→AppKit; toolbar via `NPPM_ADDTOOLBARICON_FORDARKMODE` + `toolbar.png`/`toolbar_dark.png`) → universal build → stage to `~/Library/Application Support/Nextpad++/plugins-new/<Name>/` → repo `nextpad-plus-plus-plugins/<folder>.macos`. **No host changes.** Playbook: `PORTING_PLAYBOOK.md`.

**Host capability (confirmed, no host changes needed):** the macOS host implements `NPPM_ADDTOOLBARICON_FORDARKMODE` (icon = a `toolbar.png`/`toolbar_dark.png` filename the host loads, not an HBITMAP); dialogs = programmatic AppKit; `NPPM_GETCURRENTLANGTYPE` returns canonical Windows `L_*` ids.
